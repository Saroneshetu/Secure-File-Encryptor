# 🛡️ Secure Password-Based File Encryptor/Decryptor

This project is a Python-based tool to securely encrypt and decrypt files using a password. It uses the `cryptography` library to implement strong encryption with Fernet and PBKDF2 key derivation.

## 🔧 Features

- Password-based encryption and decryption
- PBKDF2-HMAC key derivation with SHA-256
- Salt for added security
- CLI-based menu interface
- Works on all file types

## 🧪 Requirements

- Python 3.x
- `cryptography` library

Install it using:
```bash
pip install cryptography
